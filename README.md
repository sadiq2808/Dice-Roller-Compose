🎲 Dice Roller Compose

A simple Android Dice Roller application developed using Kotlin and Jetpack Compose.

Users can roll a virtual six-sided dice by clicking the Roll button. The application generates a random number between 1 and 6 and dynamically updates the dice image using Jetpack Compose State management.

Key Concepts
- Kotlin Programming
- Jetpack Compose
- State Management
- Recomposition
- Random Number Generation
- UI Components

Features
- Interactive Roll button
- Random dice values (1–6)
- Dynamic image updates
- Simple and clean user interface
